# Project 4: Authentication and Security

## Goal
Learn identity and security patterns for real FastAPI apps.

## Topics
- authentication
- JWT
- password hashing
- middleware
- CORS
- file uploads

## Tasks
1. Create a login endpoint.
2. Hash passwords safely before saving.
3. Generate a JWT token for login success.
4. Protect a route with authentication dependency.
5. Enable CORS and add a simple middleware example.
6. Add a file upload endpoint.

## Starter code
See `main.py`.

## Expected outcome
You should understand how to protect routes, manage identity, and secure user data in a FastAPI application.
