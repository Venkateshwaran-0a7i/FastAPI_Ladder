# Project 1: Python Basics for FastAPI

## Goal
Build confidence in Python features used heavily in FastAPI apps.

## Topics
- functions
- type hints
- classes
- async / await
- Pydantic models

## Tasks
1. Create functions with default and keyword arguments.
2. Add type hints to function inputs and outputs.
3. Build a small `Person` class with methods and validation.
4. Write an `async` function that simulates API work.
5. Use `pydantic.BaseModel` to validate student or user data.

## Starter code
See `main.py`.

## Expected outcome
You should understand how Python syntax and type safety support FastAPI request/response handling.
