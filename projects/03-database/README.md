# Project 3: Database with FastAPI

## Goal
Connect API logic with database operations.

## Topics
- MongoDB / MySQL
- CRUD operations
- Beanie / SQLAlchemy
- database models

## Tasks
1. Create a model for `User` or `Product`.
2. Implement create, read, update, and delete functions.
3. Connect to a database client.
4. Add validation before saving data.
5. Return database records through API endpoints.

## Suggested approach
Use either:
- MongoDB + PyMongo / Beanie
- MySQL + SQLAlchemy

## Starter code
See `main.py`.

## Expected outcome
You should understand how FastAPI interacts with persistent data and how CRUD logic is separated from API logic.
