# Project 2: FastAPI Fundamentals

## Goal
Build a simple API with common REST patterns.

## Topics
- creating an API
- routes
- GET / POST / PUT / DELETE
- path and query parameters
- request bodies
- response models
- HTTP status codes

## Tasks
1. Create a FastAPI app instance.
2. Add a root route and health-check route.
3. Add a list route and detail route.
4. Create POST, PUT, and DELETE routes.
5. Use Pydantic response models and proper status codes.

## Starter code
See `main.py`.

## Expected outcome
You should be able to build a small CRUD API with valid request/response design.
