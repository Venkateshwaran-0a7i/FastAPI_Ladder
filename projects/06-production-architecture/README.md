# Project 6: Production Architecture

## Goal
Build a scalable FastAPI project structure.

## Topics
- routers
- services
- schemas
- models
- dependency injection
- error handling
- logging
- Docker
- deployment

## Tasks
1. Split the app into `api`, `services`, `schemas`, and `models` folders.
2. Create separate router files for users and products.
3. Put business logic in services.
4. Validate inputs with schemas.
5. Add dependency injection for database/session access.
6. Add custom exception handlers and logging.
7. Prepare Docker and deployment configuration.

## Starter structure
See the `app/` folder.

## Expected outcome
You should understand how a real-world FastAPI project is organized for maintainability and production use.
