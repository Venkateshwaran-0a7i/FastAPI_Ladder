# FastAPI Learning Projects

This folder contains one mini-project for each stage of the FastAPI learning roadmap.

## Project order

1. Python basics
2. FastAPI fundamentals
3. Database integration
4. Authentication and security
5. AI-powered FastAPI apps
6. Production-ready architecture

Each project includes:
- a short objective
- task list
- starter code
- learning outcomes

## Suggested flow

- Start with the Python basics project and complete all exercises.
- Move to FastAPI fundamentals and build a working API.
- Add database features and business logic.
- Add auth, middleware, and file upload features.
- Integrate OpenAI-powered AI features.
- Finish with a production-ready app structure.

## Run projects

From the repo root:

```bash
cd projects/02-fastapi-fundamentals
uvicorn main:app --reload
```

Use a different project folder for each milestone.
